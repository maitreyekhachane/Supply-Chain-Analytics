# Python — Data Cleaning & Exploratory Data Analysis

## 📌 Overview

This folder contains the Python component of the DataCo Supply Chain Analytics project. Python was used to clean and prepare the dataset, perform feature engineering, and conduct exploratory data analysis (EDA).

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Key Activities

- Inspected dataset structure, column data types, and missing values.
- Cleaned and transformed the dataset.
- Converted order dates into datetime format.
- Created shipping delay features.
- Analyzed sales, profit, and profitability.
- Explored product, market, and customer-segment performance.
- Investigated delivery status and shipping delays.
- Identified trends, outliers, and potential business risks.

## 📊 Key Metrics

- Total records analyzed: 180,519
- Total sales: 36.78M
- Total profit: 3.97M
- Profit margin: 10.78%
- Late delivery rate: 54.83% of order-item records


## 🎯 Outcome

The Python phase prepared the data for SQL analysis and Power BI reporting while identifying important patterns in sales, profitability, and delivery performance.
