# SQL Server — Supply Chain Business Analysis

## 📌 Overview

This folder contains the SQL Server component of the DataCo Supply Chain Analytics project. SQL was used to analyze sales, profit, product performance, market trends, and delivery operations.

## 🛠️ Tools & Techniques

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
- `GROUP BY` and `ORDER BY`
- Filtering and conditional logic
- Common Table Expressions (CTEs)
- Window functions, where applicable
- Business KPI calculations

## 🔍 Key Analyses

- Overall sales and profit performance.
- Sales and profit by year, month, and quarter.
- Top-performing products and product categories.
- Market and customer-segment analysis.
- Delivery status and shipping-mode performance.
- Identification of negative-profit records.
- Month-over-month sales growth analysis.

## 📊 Key Business Metrics

- Total orders: 65,752
- Total customers: 20,652
- Total sales: 36.78M
- Total profit: 3.97M
- Profit margin: 10.78%

## 🎯 Outcome

The SQL phase converted the cleaned data into business-focused results that support product, market, profitability, and operational analysis in Power BI.
